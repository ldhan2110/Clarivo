Decisions on this screen
• One place to administer a project. Details, members and archive all live here; the edit-details modal from the earlier pass is deleted. The list page’s row menu keeps only Open / Archive / Restore.
• Owner-only page. A member has no Settings row in the sidebar and a direct URL hit returns the same “Project not found” screen — consistent with how a non-member is treated everywhere else.
• Add member is by email against an existing account. There is no invite flow and no email is sent — an unknown address is a field error, not a pending invitation.
• The owner row has no remove button. Ownership transfer is out of scope; an owner who must leave is a problem for a later change, not a half-built control here.
• Removing a member is a warning confirm, not the destructive red preset — access is revoked, nothing is deleted, and they can be added back.
• Archived settings are read-only except Restore, which replaces Archive in the danger zone.
