Decisions on this screen
• One modal, not a wizard. The reference image’s 3-step wizard (Basic info → Context → Settings) needs a draft project row to attach uploads to; a single modal avoids that whole state machine. Document upload moves to the project’s Context tab in a later change.
• Four required fields (code, name, customer / BU, domain). Objective and both dates are optional and nullable in the DB.
• Duplicate code is a field error, not a toast — it points at the input the user must change.
• A failed request keeps the dialog open with the typed values intact. Losing a filled form to a 500 is the worst outcome here.
• Archive uses the warning tone, not the destructive red confirmDelete preset — archiving is reversible, and reusing the “permanently deleted. This can’t be undone.” copy would be a lie.
