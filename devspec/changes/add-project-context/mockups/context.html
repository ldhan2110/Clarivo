Overview

Sambu Vina is a Korean-invested manufacturer in Binh Duong, Vietnam, producing automotive seat components. This project replaces a manual Excel dispatch-and-invoicing workflow with a system synced nightly to their ERP.

🌐 sambuvina.com 🌐 linkedin.com/company/sambu-vina

Scope

Invoices import from the ERP nightly at 02:00 and reconcile the next morning. Dispatch orders are raised against stock, with exceptions escalated.

Sources: SRS-v2.md §Scope

Process Flow

mermaid
ERP→ Import 02:00→ Reconcile AM→ Exception?→ Supervisor approves
Sources: Process_v1.pdf, SRS-v2.md · rendered from a mermaid block in the md

Stakeholders

  • Binh Duong warehouse supervisor — approves dispatch exceptions
  • Finance team — reviews orders above 100M VND
Sources: SRS-v2.md §Stakeholders, Current_System.docx

Constraints

Orders above 50M VND require manager approval; above 100M, finance review.

⚠ Sources differ: Current_System.docx says manager approval starts at 30M VND.
Sources: SRS-v2.md §3.2, Current_System.docx
