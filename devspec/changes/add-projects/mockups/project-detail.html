Decisions on this screen
• Sections live in the sidebar, not in page tabs. A BA works inside one project at a time, so the global Meetings / Requirements / Questions / Decisions rows become project-scoped. Keeping both would mean two routes, two query shapes and two screens per entity.
• Overview is the plan. Four pipeline stages — Context → Discovery plan → Meetings → Requirements — with real counts, plus four counters at the top. Every count is genuinely 0 today and each stage carries Soon; the later changes fill them in without the page shape changing. The reference image's 78% health ring is cut — nothing in the database can produce it, and a fake number survives into a demo.
• Members moved out of Overview into Project Settings, together with Edit details and Archive. One place to administer a project; the edit-details modal is gone.
• Settings is owner-only. A member sees no Settings row and no Settings button — nothing on that page is useful read-only.
• The project switcher has no dropdown. ← All projects already covers it; a dropdown would be a second list query for no new capability.
• Documents is gone from the global nav — it is the project's Context section. Conflicts & Gaps gets no nav row; it is an analysis view over requirements, not an entity.
• Non-member sees “Project not found”, identical to a bad id. A 403 would confirm the project exists.
